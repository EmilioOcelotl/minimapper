MiniMapper

Herramienta experimental de videomapping generativo en tiempo real, directamente en el navegador. Combina Hydra (síntesis visual live-coding) con p5.js para proyectar visuales sobre superficies deformables.

Funciona mejor en Chrome o Firefox.

Instrucciones

Hydra: Cada superficie tiene su propio editor de código Hydra y output independiente (o0–o3). CTRL+Enter o ▶ para ejecutar

Fuente: Cada superficie puede usar Hydra, Video, Imagen, Cámara o Carrusel — elige con el selector. El carrusel avanza con detección de aplauso (botón mic en la sección de carrusel)

Quads: Clic en + Quad, luego dibuja el área en el canvas con clic y arrastre. ESC cancela

Formas libres: Clic en + Libre, luego clic para colocar cada vértice. Cierra con doble clic en cualquier parte, o clic en el primer vértice (se vuelve verde). Mínimo 3 vértices. ESC cancela

Mapping: Arrastra los puntos de control para deformar la superficie. Las esquinas (rojo) están sobre la superficie; los puntos intermedios (amarillo) curvan los bordes. Mantén M al hacer clic en cualquier punto para mover toda la superficie en conjunto

Atajos: CTRL + SHIFT + H para mostrar/ocultar la UI · ESC para silenciar o cancelar · CTRL + Z para deshacer · M + clic y arrastra para mover toda la superficie

Auto-guardado: El código y los vértices se guardan automáticamente (las fuentes de video/imagen se deben recargar al abrir)

Sesión: "↓ Sesión" descarga un archivo JSON con el estado completo (imágenes incluidas). "↑ Sesión" lo restaura — los videos y la cámara se deben recargar manualmente
